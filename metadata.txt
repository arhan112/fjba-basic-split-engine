about=FjBa Basic Split Engine is a vector-processing tool for QGIS.
    It supports multiple line and polygon layers, polygon geometry repair,
    boundary extraction, line splitting and polygon attribute transfer.

    Attribute assignment uses the polygon with the longest line intersection
    for each source polygon layer.

    The output is created as a temporary in-memory vector layer and
    added to the current QGIS project.

    Features include progress reporting, a processing log and
    a cancellation request.

    Processing is synchronous in this edition. Large jobs may
    temporarily make the QGIS interface less responsive.

    QGIS 3.x and QGIS 4.x compatibility is an intended target
    and requires testing in the respective releases.
